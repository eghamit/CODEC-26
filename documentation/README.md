# Biosensor simulation documentation

LaTeX documentation for the four ISFET/BioFET simulation programs
(`biosensor_isfet.py`, `biosensor_isfet_transfer.py`, `double_layer.py`,
`biosensor_isfet_gdl.py`) built on the DDM.SPC device solver.

It covers the shared device physics, the electrolyte double-layer (G-DL) physics,
a tabular comparison of the four programs, simulated results with figures, and
the mapping to disease-detection applications.

## Files
- `main.tex` — the document source
- `main.pdf` — compiled document (8 pages)
- `figures/` — figures generated by the simulation programs

## Build
```bash
make            # or: pdflatex main.tex  (run 2-3x for cross-references)
```
Requires a LaTeX distribution (`texlive-latex-base`, `-recommended`, `-extra`,
`texlive-fonts-recommended`).
