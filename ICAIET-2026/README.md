# ICAIET-2026

**Data-Driven Surrogate Modelling for Early-Stage Ship-Hull Resistance
Prediction and Multi-Objective Design Exploration in Naval Architecture**

Conference paper prepared for the **Machine Learning and Data Science** track of
the International Conference on Artificial Intelligence and Emerging
Technologies (ICAIET 2027), XIM University, Bhubaneswar. IEEE two-column
`conference` format (`IEEEtran`).

## What the paper does

It trains and benchmarks machine-learning surrogate models that predict the
calm-water total resistance of displacement ship hulls from their principal
particulars, then uses the best surrogate to screen tens of thousands of
candidate hulls and recover a resistance-vs-transport-capability Pareto front.
The motivation is maritime decarbonisation under the IMO EEDI/EEXI/CII regime,
where cheap, fast exploration of resistance-optimal hulls is a design lever.

Headline results (all reproducible from the code here):

| Model | R² | RMSE [kN] | MAPE [%] |
|-------|-----|-----------|----------|
| Linear regression | 0.853 | 242.8 | 42.5 |
| k-NN (k=8) | 0.971 | 108.4 | 9.3 |
| Random forest | 0.988 | 68.4 | 5.4 |
| Gradient boosting | 0.995 | 45.9 | 3.4 |
| MLP (64-64-32) | 0.998 | 28.5 | 2.7 |
| Gaussian process | **0.999** | **22.0** | **1.8** |

The gradient-boosting surrogate screens ~144,000 hulls/s (≈7 µs/design) and the
recovered Pareto front agrees with the ground-truth oracle to within 3.9 % MAPE.

## Reproducing everything

Requires Python 3 with `numpy`, `scikit-learn`, `matplotlib`. Everything is
seeded, so the numbers, tables and figures are deterministic.

```bash
cd code
python3 generate_data.py     # -> ../data/hull_resistance.csv
python3 experiments.py       # -> ../data/results.json  (prints the metrics table)
python3 make_figures.py      # -> ../figures/fig1..6.png
```

## Note on the ground-truth model

The labels are produced by a **transparent semi-empirical resistance oracle**
(ITTC-1957 friction line + a fullness-dependent form factor + a
Froude-number-dependent residuary component), not by RANS CFD or towing-tank
tests. It is a controlled, reproducible stand-in of representative functional
complexity. The surrogate methodology, protocol and throughput conclusions
transfer unchanged to a dataset labelled by high-fidelity CFD or experiment;
the specific error figures would change with the label source. Validating on a
genuine CFD/experimental corpus is the primary item of future work.
