# ICAIET-2026

**Machine-Learning Surrogates for Ship-Hull Residuary Resistance: A Benchmark on
the Delft Systematic Series with Calibrated Uncertainty and Design-Space
Exploration**

A study benchmarking machine-learning surrogates for ship-hull **residuary
resistance**, trained and evaluated on **real towing-tank data** — the Delft
Systematic Yacht Hull Series (DSYHS), 308 measured experiments from the UCI
Machine Learning Repository. The motivation is maritime decarbonisation under
the IMO EEDI/EEXI/CII regime, where cheap, fast exploration of
resistance-optimal hulls is a design lever.

Headline results (all reproducible from the code here):

| Model | CV R² (mean±sd) | RMSE | MAE |
|-------|-----------------|------|-----|
| Linear regression | 0.881 ± 0.039 | 5.10 | 2.64 |
| Polynomial reg. (deg 3) — *traditional Delft regression* | 0.978 ± 0.018 | 2.04 | 0.88 |
| k-NN (k=5) | 0.410 ± 0.141 | 11.34 | 5.41 |
| SVR (RBF) | 0.992 ± 0.005 | 1.27 | 0.61 |
| Random forest | 0.995 ± 0.003 | 0.96 | 0.48 |
| Gradient boosting | 0.963 ± 0.049 | 2.29 | 1.06 |
| MLP (64-64) | 0.968 ± 0.020 | 2.55 | 1.18 |
| **Gaussian process** | **0.999 ± 0.001** | **0.46** | **0.20** |

The Gaussian process is the most accurate model, beats the traditional
polynomial regression ~4.5× on RMSE, and its 95% predictive intervals are
well calibrated (**98.4%** empirical coverage). It then screens ~72,000 hulls/s
to recover a displacement–resistance Pareto front within the measured envelope.
Metrics are 10×-repeated 10-fold cross-validation.

## Two formatted versions

The same study is provided in two formats, both compiling cleanly from the
shared figures and numbers:

- **`paper.tex`** — IEEE `IEEEtran` two-column conference format (ICAIET 2027,
  Machine Learning and Data Science track). 6 pages.
- **`jmst-springer/manuscript.tex`** — Springer Nature `sn-jnl` single-column
  journal format for the *Journal of Marine Science and Technology*. 13 pages.

## Reproducing everything

Requires Python 3 with `numpy`, `scikit-learn`, `matplotlib`. Everything is
seeded, so the numbers, tables and figures are deterministic (the
cross-validation step takes a few minutes).

```bash
cd code
python3 experiments.py       # -> ../data/results.json  (prints the metrics table)
python3 make_figures.py      # -> ../figures/fig1..7.png
```

## Compiling the IEEE paper

Requires a LaTeX distribution providing `IEEEtran`, `siunitx`, `booktabs`,
`amsmath`.

```bash
pdflatex paper && pdflatex paper
```

## Data

The labels are **real physical measurements** (Delft towing tank), not synthetic
values. See `data/DATA_SOURCE.md` for provenance, the column definitions, and
the primary reference (Gerritsma et al., 1981). The target is residuary
(chiefly wave-making) resistance per unit weight of displacement; frictional
resistance is handled separately by classical correlation lines and is out of
scope here.
